# 출력 및 로그

도구가 출력(print)하거나 기록하는 모든 로그는 도구가 실행되는 동안 폼 하단의 출력 콘솔에 실시간으로 표시됩니다. 로그 레벨별로 색상이 구분되며, 일반적인 ``print`` 출력 역시 로그와 구분할 수 있도록 고유한 색상으로 표시됩니다.

애플리케이션에서 켜 두었다면 성공한 실행의 반환값이 출력 끝에 표시됩니다. 빈 줄 하나와 ``========== 결과 ==========`` 구분선 다음에 값이 이어집니다. 실패하거나 취소된 실행, 반환값이 없는 실행에서는 아무것도 표시되지 않습니다.

* ``복사``(``Copy``): 콘솔의 전체 내용을 클립보드에 복사합니다.
* ``로그 보기``(``View Log``): 이번 실행 출력을 크기 조절이 가능한 별도 창에서 엽니다.

출력 내용이 많을 때는 로그 창을 사용하는 것이 좋습니다. 로그 창에는 다음과 같은 기능이 제공됩니다:

* 로그 레벨별 토글 버튼: ``DEBUG``를 꺼서 중요한 로그만 확인하거나, ``없음``(``None``)을 누른 후 ``ERROR``만 켜서 오류만 확인할 수 있습니다.
* 일치하는 라인을 필터링하는 검색 상자.
* ``모두 복사``(``Copy All``) 버튼.

로그 창에서 필터링을 수행해도 원래 페이지의 콘솔 내용에는 영향을 주지 않습니다. 로그 창은 독립된 로그 복사본을 유지합니다.

실행 출력은 저장되므로, 탭을 닫은 지 한참 지난 후에도 실행 기록에서 동일한 로그를 다시 열어볼 수 있습니다.
