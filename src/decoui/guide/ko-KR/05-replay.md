# 매개변수 재사용

매개변수 재사용(Replay) 기능은 이전 실행의 인수를 폼으로 복원합니다. 자동으로 다시 실행되는 것은 **아닙니다**. 사용자가 직접 ``실행``(``Run``)을 누르기 전까지는 아무것도 실행되지 않습니다. 이는 중요한 변경을 수반하는 작업을 복원한 후, 한 가지 필드만 수정한 뒤 실행 여부를 결정할 수 있도록 의도된 설계입니다.

두 가지 접근 방법이 있습니다:

* 도구 페이지에서: ``매개변수 재사용``(``Replay``)을 누르면 해당 도구로 이미 필터링된 기록 창이 열려, 전체가 아닌 해당 도구의 실행 기록 중에서 선택할 수 있습니다.
* 기록 페이지에서: 원하는 행을 선택하고 ``매개변수 재사용``(``Replay Params``)을 누릅니다.

저장된 스냅샷은 텍스트 형태이므로, 값은 문자열 형태로 복원된 후 도구가 다음에 실행될 때 다시 변환됩니다. 예를 들어 파일 경로는 경로 객체가 아닌 문자열 형태로 복원되며, 도구는 사용자가 직접 입력한 것과 동일하게 이를 다시 읽어들입니다.
