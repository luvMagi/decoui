# 실행 기록

어떤 도구가 실행되었는지, 전달된 인수, 출력 내용, 종료 상태, 소요 시간 등 모든 실행 내역이 기록됩니다. 사이드바 하단의 ``기록``(``History``) 버튼을 누르면 이 기록을 열 수 있습니다.

행을 선택하면 하단 세부 정보 패널에 해당 실행의 매개변수가 표시되며, 두 가지 작업을 수행할 수 있습니다:

* ``매개변수 재사용``(``Replay Params``) — 다음 페이지를 참조하세요.
* ``전체 로그 보기``(``View Full Log``) — 해당 실행에서 생성된 콘솔 출력을 다시 엽니다.

필터 행을 사용하면 도구별 및 상태별로 목록을 좁힐 수 있으며, "어떤 실행이 실패했는지"를 확인하는 가장 빠른 방법입니다.

유지 관리 기능도 동일한 페이지에서 제공됩니다: ``새로고침``(``Refresh``)은 데이터베이스를 다시 읽고, ``선택 항목 삭제``(``Delete Selected``)는 체크된 행을 삭제하며, ``기록 지우기``(``Clear History``)는 모든 기록을 완전히 삭제하여 디스크 공간을 확보합니다. 현재 데이터베이스 크기는 이 버튼들 옆에 표시됩니다.

``닫기``(``Close``)를 누르면 직전에 보고 있던 도구 화면으로 돌아갑니다.
