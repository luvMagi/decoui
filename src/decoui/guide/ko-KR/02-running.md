# 도구 실행

도구의 입력 폼은 해당 함수의 선언된 매개변수를 바탕으로 자동 생성되므로, 각 도구에 필요한 입력 필드가 표시됩니다.

* 빨간색 별표(*)가 표시된 필드는 필수 입력 항목이며 기본값이 없습니다.
* 입력을 마친 후 ``매개변수``(``Parameters``)를 클릭하면 폼이 접혀 출력 영역을 더 넓게 볼 수 있습니다.
* ``실행``(``Run``)을 누르면 도구가 시작됩니다. 실행 중에는 ``실행`` 버튼이 ``중지``(``Stop``)로 변경됩니다.
* ``초기화``(``Reset``)를 누르면 모든 필드가 선언된 기본값으로 되돌아갑니다.

일부 도구는 실행 전 확인을 요청할 수 있습니다. 이는 도구 자체에서 선언한 것이며 애플리케이션이 임의로 결정하는 것이 아닙니다.

``중지``는 실행 중인 도구를 중단합니다. 순수 연산 작업이나 대기(sleep) 상태인 도구는 즉시 중지됩니다. 외부 프로그램을 기다리는 도구의 경우, 개발자가 해당 상황에 대한 정리(cleanup) 로직을 구현해 둔 경우에만 중지됩니다. 그렇지 않으면 외부 프로그램이 계속 실행되는 동안 페이지만 대기(idle) 상태로 돌아갑니다.

진행률 표시줄은 전체 작업량이 지정되지 않은 경우 좌우로 반복 이동하며, 작업량이 지정된 경우 실제 백분율 진행률을 표시합니다.
