# 시작하기

이 애플리케이션의 모든 도구는 소속된 툴셋별로 그룹화되어 왼쪽 사이드바에 나열됩니다. 도구를 하나 선택하면 새로운 탭으로 열립니다.

여러 도구를 동시에 열어둘 수 있으며, 각 도구는 독립적으로 실행됩니다. 한 탭에서 오래 걸리는 작업을 시작해도 다른 탭의 작업이 차단되지 않습니다. 탭을 닫아도 실행 중인 도구가 중지되는 것은 **아닙니다**. 작업은 백그라운드에서 완료되며 평소와 같이 실행 기록에 저장됩니다.

상단에 나열된 알약 모양의 버튼을 사용하면 태그별로 사이드바를 필터링할 수 있습니다. 여러 태그를 선택하면 해당 태그 중 하나가 아닌, 선택한 *모든* 태그를 포함하는 그룹으로 목록이 좁혀집니다. ``전체``(``All``)를 누르면 필터가 초기화됩니다.

사이드바 상단의 검색 상자를 통해 도구 이름으로 필터링할 수 있습니다.
