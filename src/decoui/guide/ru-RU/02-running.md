# Запуск инструмента

Форма ввода инструмента формируется на основе параметров, объявленных в его функции, поэтому поля формы точно соответствуют требованиям конкретного инструмента.

* Поле, отмеченное красной звездочкой (*), является обязательным и не имеет значения по умолчанию.
* Кнопка ``Параметры`` (``Parameters``) сворачивает форму после заполнения, освобождая больше места для области вывода.
* Кнопка ``Запустить`` (``Run``) запускает выполнение инструмента. Во время работы она заменяется на кнопку ``Остановить`` (``Stop``).
* Кнопка ``Сбросить`` (``Reset``) возвращает все поля к их значениям по умолчанию.

Некоторые инструменты запрашивают подтверждение перед запуском; это задается самим инструментом, а не приложением.

Кнопка ``Остановить`` прерывает выполнение инструмента. Инструмент, выполняющий только вычисления или находящийся в режиме ожидания (sleep), останавливается немедленно. Если инструмент ожидает внешнюю программу, он остановится только в том случае, если разработчик предусмотрел логику очистки для этой ситуации — иначе страница вернется в режим ожидания, пока внешняя программа продолжает работу.

Индикатор выполнения перемещается вперед-назад, если инструмент не указал общий объем работы, и показывает точный процент выполнения, когда он известен.
