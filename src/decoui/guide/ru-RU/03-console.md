# Вывод и журналы

Всё, что инструмент выводит (print) или записывает в журнал, отображается в режиме реального времени в консоли вывода под формой во время выполнения. Уровни ведения журнала выделены цветом, а стандартный вывод ``print`` отображается собственным цветом для удобного отличия от записей журнала.

Если приложение это включило, возвращаемое значение успешного запуска печатается в конце вывода: пустая строка, разделитель ``========== Результат ==========``, затем само значение. Для неудачного или отменённого запуска, а также когда возвращать нечего, не печатается ничего.

* ``Копировать`` (``Copy``) — копирует всё содержимое консоли в буфер обмена.
* ``Просмотр журнала`` (``View Log``) — открывает вывод текущего запуска в отдельном окне с изменяемым размером.

Окно журнала особенно удобно при большом объеме вывода. Оно предоставляет следующие возможности:

* Переключатели уровней журнала — отключите ``DEBUG``, чтобы видеть только важное, или нажмите ``Нет`` (``None``), а затем ``ERROR``, чтобы просматривать только ошибки.
* Поле поиска для фильтрации строк.
* Кнопка ``Копировать всё`` (``Copy All``).

Фильтрация в окне журнала никак не влияет на консоль на исходной странице; окно работает с собственной копией строк.

Вывод каждого запуска сохраняется, поэтому тот же журнал можно снова открыть из истории спустя долгое время после закрытия вкладки.
