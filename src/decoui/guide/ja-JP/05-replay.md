# パラメータの再利用

「再実行（Replay）」機能は、過去の実行時の引数をフォームに復元します。自動的に再実行されることは**ありません**。ご自身で ``実行``（``Run``）を押すまで何も実行されません。これは意図的な設計であり、破壊的な処理を伴う実行を復元し、1つの項目だけを変更してから実行を決定できるようにするためです。

利用方法は2通りあります:

* ツール画面から: ``再実行``（``Replay``）を押すと、そのツールで絞り込まれた状態で履歴が開き、すべての履歴からではなくそのツールの実行履歴から選択できます。
* 履歴画面から: 任意の行を選択し、``パラメータを再利用``（``Replay Params``）を押します。

保存されるスナップショットはテキスト形式のため、値は文字列として復元され、ツールが次回実行される際に再変換されます。例えばファイルパスはパスオブジェクトではなく文字列形式として復元され、キーボードから入力した場合とまったく同様にツールによって再読み込みされます。
