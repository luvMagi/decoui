# ツールの実行

ツールの入力フォームは、その関数の定義されたパラメータに基づいて構築されるため、入力項目はそのツールが必要とする内容になります。

* 赤いアスタリスク（*）が付いている項目は必須であり、デフォルト値はありません。
* ``パラメータ``（``Parameters``）をクリックするとフォームを折りたたむことができ、出力領域をより広く表示できます。
* ``実行``（``Run``）でツールを開始します。実行中は ``実行`` ボタンが ``停止``（``Stop``）に切り替わります。
* ``リセット``（``Reset``）を押すと、すべての項目が定義されたデフォルト値に戻ります。

一部のツールでは開始前に確認ダイアログが表示されます。これはツール側で設定されているものであり、アプリケーションが自動的に判断しているわけではありません。

``停止`` は実行中のツールを中断します。計算処理やスリープ状態のツールは即座に停止します。外部プログラムの完了を待機しているツールの場合は、ツールの開発者がクリーンアップ処理を実装している場合にのみ停止します。そうでない場合、外部プログラムが動作を継続したまま、UI上は待機状態（アイドル）に戻ります。

進捗バーは、全体の処理量が指定されていない場合は左右に往復アニメーションし、指定されている場合は具体的なパーセンテージを表示します。
