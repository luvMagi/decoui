# Historique des Exécutions

Chaque exécution est consignée : l'outil utilisé, les arguments fournis, les sorties générées, le statut final et la durée de traitement. Le bouton ``Historique`` (``History``) situé en bas de la barre latérale ouvre cette liste.

Sélectionnez une ligne pour afficher les paramètres de cette exécution dans le panneau de détails ci-dessous, avec deux actions possibles :

* ``Réutiliser les paramètres`` (``Replay Params``) — voir la page suivante.
* ``Voir le journal complet`` (``View Full Log``) — rouvre la sortie de console produite par cette exécution.

La barre de filtre permet d'affiner la liste par outil et par statut, ce qui constitue le moyen le plus rapide de répondre à la question « quelles sont les exécutions qui ont échoué ? ».

Les fonctionnalités de maintenance se trouvent sur la même page : ``Actualiser`` (``Refresh``) recharge la base de données, ``Supprimer la sélection`` (``Delete Selected``) supprime les lignes cochées et ``Effacer l'historique`` (``Clear History``) vide intégralement les enregistrements pour libérer de l'espace disque. La taille actuelle de la base de données est indiquée à côté de ces boutons.

``Fermer`` (``Close``) vous ramène à l'outil que vous consultiez.
