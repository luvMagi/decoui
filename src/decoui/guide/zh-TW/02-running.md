# 執行工具

工具的表單是根據其函式宣告的參數自動構建的，因此表單欄位與該特定工具所需的參數完全對應。

* 帶有紅色星號（*）的欄位為必填項目，且沒有預設值。
* 填寫完畢後，點擊 ``參數``（``Parameters``）可以摺疊表單，從而為輸出區域留出更多空間。
* 點擊 ``執行``（``Run``）即可啟動工具。執行過程中，``執行`` 按鈕會變為 ``停止``（``Stop``）。
* 點擊 ``重設``（``Reset``）可將每個欄位恢復為其宣告的預設值。

某些工具在啟動前會請求確認；這是由工具本身宣告的，而不是由應用程式決定的。

``停止`` 可以中斷正在執行的工具。僅進行純運算或處於休眠（sleep）狀態的工具會立即停止。而正在等待外部程式的工具，僅在其作者為該情況撰寫了清理邏輯時才會停止——否則頁面將返回閒置狀態，而外部程式仍會繼續執行。

當工具未指定工作總量時，進度列會左右來回擺動；當指定了工作總量時，則會顯示具體的百分比進度。

一次執行結束之後，對它的回傳值可以做三件事：

* ``複製回傳值``（``Copy Result``）：把值複製到剪貼簿。
* ``傳送回傳值``（``Send Result``）：把值填進另一個工具的輸入欄，並開啟那個工具、切到它的分頁。
  只有當確實存在宣告接受這類值的工具時，這個按鈕才會出現；輸入欄原有的內容
  會被覆蓋。
* 應用程式還可能設定了把值列印到輸出主控台 —— 見下一頁。

兩個按鈕都會在滑鼠提示裡顯示這個值；在執行回傳內容之前，它們都是停用的。
