# Execution History

Every run is recorded: which tool, the arguments it was given, what it printed,
how it ended and how long it took. The ``History`` button at the bottom of the
sidebar opens the record.

Select a row and the detail panel below shows that run's parameters, with two
actions:

* ``Replay Params`` -- see the next page.
* ``View Full Log`` -- reopen the console output that run produced.

The filter row narrows the list by tool and by status, which is the quickest way
to answer "what did I run that failed".

Housekeeping lives on the same page: ``Refresh`` re-reads the database,
``Delete Selected`` removes the ticked rows, and ``Clear History`` empties the
record entirely and reclaims the disk space. The current database size is shown
beside those buttons.

``Close`` returns to the tool you were looking at.
