# Getting Started

Every tool in this application is listed in the sidebar on the left, grouped by
the toolset it belongs to. Select one and it opens as a tab.

Several tools can be open at once, and each runs independently -- starting a
long job in one tab does not block another. Closing a tab does **not** stop a
tool that is still running: it finishes and is recorded in history as usual.

The row of pills along the top filters the sidebar by tag. Selecting more than
one narrows the list to groups carrying *all* of them, not any of them. Press
``All`` to clear the filter.

The search box above the sidebar filters by tool name.
