# 运行工具

工具的表单是根据其函数声明的参数自动构建的，因此表单字段与该特定工具所需的参数完全对应。

* 带有红色星号（*）的字段为必填项，且没有默认值。
* 填写完毕后，点击 ``参数``（``Parameters``）可以折叠表单，从而为输出区域留出更多空间。
* 点击 ``运行``（``Run``）即可启动工具。运行过程中，``运行`` 按钮会变为 ``停止``（``Stop``）。
* 点击 ``重置``（``Reset``）可将每个字段恢复为其声明的默认值。

某些工具在启动前会请求确认；这是由工具本身声明的，而不是由应用程序决定的。

``停止`` 可以中断正在运行的工具。仅进行纯计算或处于睡眠状态的工具会立即停止。而正在等待外部程序的工具，仅在其作者为该情况编写了清理逻辑时才会停止——否则页面将返回空闲状态，而外部程序仍会继续运行。

当工具未指定工作总量时，进度条会左右来回摆动；当指定了工作总量时，则会显示具体的百分比进度。
